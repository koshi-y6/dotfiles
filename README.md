# dotfiles

macOS用の個人設定です。

## Setup

```sh
xcode-select --install
git clone https://github.com/koshi-y6/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

## Contents

- Homebrew packages and applications
- zsh
- Neovim / IdeaVim
- tmux
- WezTerm
- Hammerspoon
- mise runtimes

秘密鍵、認証情報、ローカルデータは含みません。
